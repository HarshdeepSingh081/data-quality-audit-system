# GlobalMart Inc. - Data Quality Audit System

## Project Overview
A comprehensive data quality audit and reporting system for GlobalMart Inc., a multinational retail corporation. This system performs automated data quality checks on customer, product, and order data stored in MySQL database and generates detailed audit reports in multiple formats.

## Features
- Automated data extraction from MySQL database
- Multiple data quality checks:
  - Completeness (missing values)
  - Uniqueness (duplicate records)
  - Email format validation
  - Date consistency validation
  - Range validity checks
- Report generation in multiple formats:
  - JSON (machine-readable)
  - CSV (spreadsheet compatible)
  - HTML (human-readable with styling)
- Comprehensive audit summary with pass/fail status

## Technology Stack
- **Python 3.8+** - Core programming language
- **MySQL** - Database management
- **PyCharm** - Development IDE
- **Libraries**: mysql-connector-python, pandas, numpy
